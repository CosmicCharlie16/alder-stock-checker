# Alder Stock Checker

A single-page stock checker for Alder, a fictional home goods shop. Open `index.html` in a browser — no build step or dependencies.

- Searchable, sortable inventory table (product, category, stock, price)
- Category filter and a "low stock only" toggle (10 units or fewer)
- Bar chart of units by category (click a bar to filter)
- Reorder list, light and dark themes, responsive layout
